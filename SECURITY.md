# Security policy

## Supported versions

Only the latest deployment of `main` receives fixes.

## Reporting a vulnerability

- Report it privately through GitHub: **Security → Report a vulnerability** on this repository.
- Do not open a public issue.
- Include the endpoint, the request, what an attacker gains and how to reproduce it.
- Expect a first answer within 3 working days.

## Scope

- In scope: this API, its WebSocket channel, the worker and the AWS infrastructure in `infra/`.
- Out of scope: the iOS and Android apps (report in their own repositories).
